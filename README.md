# Python File Handling System

A beginner-friendly Python project that demonstrates file handling using Python's built-in `pathlib` module.

## Features

- Create new files
- Read file contents
- Update existing files
- Rename files
- Overwrite file content
- Append new content
- Delete files with confirmation
- List files and folders
- Menu-driven command-line interface

## Technologies Used

- Python 3
- pathlib
- File handling
- Exception handling
- Functions and conditional statements

## How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python file_handling.py
```

## Learning Objectives

This project helps beginners understand file creation, reading, writing, appending, renaming, deleting, and exception handling in Python.
